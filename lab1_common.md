•	What is a processor?
A processor is the brain of the computer< its only job is to follow instructions extremely quickly. It takes numbers, adds them, compares them and moves them around.
•	What is memory?
Memory is the computer’s storage space. When the program is running, the memory needs a place to hold information, like numbers, text or images so the processor can reach them.
•	The difference between main memory (RAM) and processor memory (registers)
The ram can hold a lot of stuff, but it takes time for the processor to walk over and reach them. The processor memory registers live directly inside the CPU chip. They can hold a few tiny pieces of data at a time but access it instant.
•	What is an instruction?
An instruction tells the processor to do one basic action.
•	What is an Instruction Set Architecture?
The Instruction set architecture is the language dictionary that a specific processor understands. Different processor speaks different languages, like Intel processors speak x86 or apple macs speak ARM.
•	Why do instructions need an identifier?
Because computers only understand 1s and 0s, they cannot read words like add or multiply. Every instruction gets a unique numerical ID called an opcode. 
•	What is machine code?
Machine code is the raw stream of 1s and 0s containing those instruction identifiers and data values. 
•	What is a memory address?
Every single byte in your ram has a unique number assigned to it, starting from 0 up to billions. That number is its memory address.
•	What is a byte?
A byte is the basic unit used to measure memory size, a single 1 or 0 is called a bit. 8 bits grouped together is one byte.
