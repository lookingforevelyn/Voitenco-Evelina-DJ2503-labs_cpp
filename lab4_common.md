•	How should you approach solving complex problems?
First, you need to analyze the whole task, then, break it down into sub-level tasks (smaller and easy one). After that, you should analyze the sub-level tasks and break them down into even smaller ones if it is required till you will reach the basic, or with the solution already. 
•	How can a list of numbers be represented in linear memory?
A list of numbers can be stored in consecutive memory locations. Each number takes some bytes, and the numbers are stored one after another, for example 10, 20 can be stored in memory like [10] [20].
•	What needs to be done to iterate over every element in a list? To calculate the sum of the list elements?
In every cases you need a memory cell that will hold the sum of the current value or the index.
•	Give an example of an algorithm that uses another algorithm during its execution.
An algorithm that uses another one is the sorting algorithm that uses the comparison one. For example, you have numbers 2, 1 and 3. You need an algorithm for comparison which one is smaller, and another one to sort the numbers.
